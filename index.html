보안 안내
GitHub Pages는 정적 웹사이트라 API 비밀 키를 안전하게 보관할 수 없어. API 키를 이 HTML 코드에 직접 넣지 마. AI를 실제로 연결하려면 Cloudflare Worker 같은 서버리스 중계 주소가 필요해.

주소를 저장한 후 연결을 테스트해 봐.

AI 문제 생성 방식

이 사이트는 Worker에 다음 형식으로 요청하도록 작성돼 있어.

POST / 
Content-Type: application/json

{
  "action": "generate",
  "count": 25,
  "topic": "한국 근현대사",
  "events": ["사건 자료 목록"]
}

Worker는 아래 형식의 JSON을 반환해야 해.

{
  "questions": [
    {
      "q": "문제 내용",
      "o": ["선지 1", "선지 2", "선지 3", "선지 4"],
      "a": 0,
      "e": "정답 해설",
      "r": "관련 사건 또는 출처"
    }
  ]
}

a는 정답 선지의 번호로, 첫 번째 선지가 정답이면 0이야. AI가 반환한 역사적 사실은 교과서나 신뢰할 수 있는 사료로 확인해야 해.
